\# ❌⭕ XO Game



A simple console-based Tic-Tac-Toe (XO Game) developed in Java. This project allows two players to play the classic XO game in the terminal.



\## ✨ Features



\- 🎮 Two Player Mode

\- ❌ Player 1 uses \*\*X\*\*

\- ⭕ Player 2 uses \*\*O\*\*

\- 🏆 Automatic Winner Detection

\- 🤝 Draw Detection

\- 🚫 Invalid Position Validation

\- ⚠️ Prevents Overwriting an Occupied Position

\- 📋 Displays the Game Board After Every Move



\## 🛠 Technologies Used



\- Java

\- IntelliJ IDEA

\## ▶️ How to Run



1\. Clone the repository.



```bash

git clone https://github.com/your-username/XO\_Game.git

```



2\. Open the project in IntelliJ IDEA.



3\. Run `Start\_Game.java`.



4\. Enter \*\*Y\*\* to start the game.



5\. Players take turns entering positions (1–9).
